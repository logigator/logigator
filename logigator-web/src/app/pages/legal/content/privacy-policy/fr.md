## Fonctionnement du site

Logigator fonctionne sur ses propres serveurs en Autriche. Les sauvegardes de la base de données sont également conservées en Autriche.

**Cloudflare.** Toutes les requêtes vers logigator.com passent par Cloudflare, Inc. (États-Unis), qui protège le site contre les attaques et le diffuse rapidement. Cloudflare traite à cette occasion votre adresse IP et les données techniques de la requête.

**Journaux du serveur.** À chaque requête, nos serveurs enregistrent l’adresse IP, l’heure, l’adresse demandée, le navigateur et le résultat. Nous en avons besoin pour trouver les pannes et détecter les abus. Ils sont supprimés au bout d’un mois.

**Protection contre les abus.** Pour freiner les tentatives de connexion répétées et les inscriptions en masse, le serveur compte les requêtes par adresse IP. Ce compteur expire au bout d’une heure au plus.

La base juridique est notre intérêt légitime à un fonctionnement sûr et fiable (art. 6, par. 1, point f du RGPD).

## Votre compte

Pour un compte, nous enregistrons votre nom d’utilisateur, votre adresse e-mail et votre mot de passe, ce dernier uniquement sous forme d’empreinte irréversible. Si vous vous connectez avec Google, nous enregistrons l’identifiant de votre compte Google au lieu d’un mot de passe. Vous pouvez ajouter, si vous le souhaitez, une photo de profil, une description, un site web et jusqu’à trois liens vers des réseaux sociaux.

Après votre inscription, nous vous envoyons un e-mail pour confirmer votre adresse. Les comptes dont l’adresse n’est pas confirmée dans les trois mois sont supprimés.

Tant que vous êtes connecté, votre navigateur conserve un cookie de session. La session prend fin 30 jours après votre dernière utilisation, ou lorsque vous vous déconnectez.

Vous pouvez supprimer votre compte à tout moment dans les paramètres du compte. Tous vos circuits et vos étoiles sont alors supprimés aussi. Les données disparaissent des sauvegardes lorsque celles-ci sont remplacées, au bout de trois mois.

La base juridique est l’exécution des conditions d’utilisation (art. 6, par. 1, point b du RGPD).

## Circuits et communauté

Les circuits que vous enregistrez dans le cloud sont stockés sur nos serveurs, avec leur nom, leur description et leur aperçu. Vous choisissez qui peut les voir :

- **Vous uniquement** : personne d’autre que vous.
- **Toute personne avec le lien** : quiconque a le lien peut voir le circuit. Il n’apparaît dans aucune liste ni dans aucun moteur de recherche.
- **Tout le monde** : le circuit apparaît dans la communauté, est visible par tous et est indexé par les moteurs de recherche.

Votre profil public affiche votre nom d’utilisateur, votre photo de profil, les informations de votre profil, votre date d’inscription, vos circuits publics et les circuits publics auxquels vous avez donné une étoile. Sur un circuit public, chacun peut voir qui lui a donné une étoile. Quand quelqu’un copie un circuit, la copie renvoie à l’original.

La base juridique est l’exécution des conditions d’utilisation (art. 6, par. 1, point b du RGPD). Les données sont conservées jusqu’à ce que vous les supprimiez, ou votre compte.

## Cookies et stockage dans le navigateur

Sans votre consentement, nous n’enregistrons que ce dont le site et l’éditeur ont besoin pour fonctionner (§ 165, al. 3 de la loi autrichienne sur les télécommunications de 2021) :

- `preferences` : votre langue et votre thème, un an.
- `consent` : votre choix concernant les cookies, un an.
- `lg_sid` et `isAuthenticated` : votre connexion, jusqu’à 30 jours.
- Dans le stockage local du navigateur : les réglages de l’éditeur et les projets enregistrés dans le navigateur. Ces données ne quittent pas votre navigateur, sauf si vous envoyez un projet dans le cloud.

Tout le reste n’est utilisé qu’avec votre consentement. Vous pouvez le modifier ou le retirer à tout moment via « Paramètres des cookies », dans le pied de page du site ou dans le menu Aide de l’éditeur.

## Statistiques avec PostHog

Si vous y consentez, nous utilisons PostHog pour comprendre comment Logigator est utilisé et pour trouver les pannes. Le fournisseur est PostHog, Inc. (États-Unis). Les données sont stockées dans l’UE (PostHog Cloud EU, Francfort).

PostHog enregistre :

- les pages que vous ouvrez et, sur le site, ce sur quoi vous cliquez,
- les fonctions de l’éditeur que vous utilisez,
- des enregistrements de vos sessions dans l’éditeur, c’est-à-dire ce qui se passe à l’écran de l’éditeur, y compris la surface de dessin ; le texte saisi dans les champs est masqué,
- les messages d’erreur avec leurs détails techniques,
- les temps de chargement, le navigateur, le système d’exploitation, la taille de l’écran et la langue de l’interface.

Les données sont associées à un identifiant aléatoire, conservé dans un cookie (`ph_…_posthog`) et dans le stockage local du navigateur. Nous ne les relions pas à votre compte. Une localisation approximative (pays et région) est déduite de votre adresse IP ; l’adresse IP elle-même n’est pas enregistrée.

Les événements sont supprimés au bout d’un an, les enregistrements au bout de 30 jours. Sans votre consentement, PostHog n’est pas chargé ; si vous le retirez, plus aucune donnée n’est enregistrée.

La base juridique est votre consentement (art. 6, par. 1, point a du RGPD, § 165, al. 3 de la loi autrichienne sur les télécommunications de 2021).

## Rapports de bug

Vous pouvez signaler un bug depuis l’éditeur. Un rapport n’est envoyé que lorsque vous cliquez sur « Envoyer le rapport ». Il contient votre description, le message d’erreur avec ses détails techniques, des informations sur votre navigateur, votre système d’exploitation, votre carte graphique et votre écran, l’adresse où vous vous trouviez, les dernières lignes du journal de l’éditeur, le projet ouvert et, si vous êtes connecté, l’identifiant de votre compte.

Le rapport nous parvient par e-mail et est noté dans le journal du serveur. Nous le supprimons dès que le bug est corrigé, et au plus tard au bout de six mois.

La base juridique est notre intérêt légitime à corriger les bugs (art. 6, par. 1, point f du RGPD).

## Connexion avec Google

Si vous choisissez « Continuer avec Google », Logigator vous redirige vers Google Ireland Limited. Google nous transmet l’identifiant de votre compte Google, votre adresse e-mail, votre nom et votre photo de profil. Nous utilisons le nom comme suggestion pour votre nom d’utilisateur et copions la photo de profil sur notre serveur. Google apprend ainsi que vous vous connectez à Logigator.

La base juridique est l’exécution des conditions d’utilisation (art. 6, par. 1, point b du RGPD).

## Vidéo de la page d’accueil

La vidéo explicative de la page d’accueil provient de YouTube (Google Ireland Limited). Elle ne se charge que lorsque vous cliquez dessus ; avant cela, YouTube ne reçoit aucune donnée. La base juridique est le consentement que vous donnez par ce clic (art. 6, par. 1, point a du RGPD, § 165, al. 3 de la loi autrichienne sur les télécommunications de 2021).
